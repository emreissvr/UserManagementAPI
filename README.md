# User Management API

A simple ASP.NET Core Web API project built for internal HR/IT tools at TechHive Solutions. Built using GitHub Copilot.

## Features

- Full CRUD operations for user management
- Input validation (required fields, valid email)
- Middleware:
  - Logging (method, path, response code)
  - Global error handling
  - Token-based authentication
- Built with Copilot guidance and scaffolding

## How to Run

```bash
dotnet run
```
